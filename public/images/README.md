# Зображення для сайту

Додайте сюди скріншоти та зображення:

- **hero.png** — геройське зображення / скріншот інтерфейсу CRM (головна сторінка).
- **statistic.png** — скріншот дашборду або звітів (блок «Переваги» / Benefits).
- **task.png** — завдання та можливості CRM (блок «Можливості» / Features).
- **business.png** — ілюстрація для секції призиву до дії / CTA.

Як додати геройське зображення:
1. Відкрийте [HeroImg.png на Google Drive](https://drive.google.com/file/d/1wGY36r8-D0lEn4mtKjUqcs1pC9PTb2mq/view?usp=sharing).
2. Завантажте файл (три крапки → Завантажити).
3. Перейменуйте на `hero.png` і покладіть у цю папку: `public/images/hero.png`.

Після цього зображення з’явиться на головній сторінці.
