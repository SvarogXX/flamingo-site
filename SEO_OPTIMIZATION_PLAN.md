### 🎯 РЕКОМЕНДОВАНІ ДО ДОДАВАННЯ:

#### 1. **FAQ Schema** - КРИТИЧНО (для /faq)

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Що таке CRM?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "CRM (Customer Relationship Management) — система для управління..."
      }
    }
  ]
}
```

**Очікуваний результат:** +20% клік-через з Google SERP (FAQ snippets)

#### 2. **Product Schema** - для /pricing

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Flamingo CRM Starter",
  "description": "CRM для малого бізнесу",
  "offers": {
    "@type": "Offer",
    "price": "9",
    "priceCurrency": "USD",
    "availability": "https://schema.org/InStock"
  }
}
```

#### 3. **Service Schema** - для /features та /for-whom

```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "Управління клієнтами в CRM",
  "description": "Система для управління контактами клієнтів",
  "provider": {
    "@type": "Organization",
    "name": "Flamingo CRM"
  }
}
```

#### 4. **Article Schema** - для блогу (вже може бути)

```json
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "Автоматизація обробки лідів",
  "articleBody": "...",
  "datePublished": "2026-03-08"
}
```

#### 5. **BreadcrumbList Schema** - для навігації

```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "name": "Flamingo", "item": "/" },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Функціонал",
      "item": "/features"
    }
  ]
}
```
